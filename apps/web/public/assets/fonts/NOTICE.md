- https://github.com/JetBrains/JetBrainsMono — SIL OFL 1.1

Note: opencode ships the *Nerd Font* patched build of JetBrains Mono, which adds
several thousand terminal glyphs. Picone renders no terminal glyphs, so the
stock webfont build is used instead — same letterforms, roughly a tenth of the
download.
